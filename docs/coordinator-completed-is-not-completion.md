# Coordinator "Completed" Is Not Completion

**Law — recorded 2026-09-21.** A coordinator's or subagent's
"completed"/exit status does not mean the work is done — verify the
deliverables on disk (files, byte sizes, QA records) before reporting
completion.

coordinator, and the 1AxRnZVLakVxl coordinator all returned "completed" with
unfinished render/upload/recap work behind them.
