# Department Heads + PM Chat Wiring

**Law — approved by Frank 2026-09-22.** Two department heads report directly
to Gilbert (Main): the Project Manager (execution, roadmaps, forward
progression, drift elimination) and the Media Manager (Media QA room —
quality, spec, brand for everything outward-facing; the QA Supervisor
PASS/FAIL gate lives inside it). Nothing reaches Frank except through Main.

## Chat wiring

- Every lane chat is wired into the PM's registry (`~/workspace/pm/chat-registry.md`).
- The PM pulls a status update from every chat on the daily verification pass
  (transcript read + live-destination checks) without changing room reporting
  flows — rooms keep reporting to Main as usual.

## Project standard

Every project carries: end-state expectation, quality expectation, roadmap,
gates, QA, drift management. Drift protocol: daily movement; 48h silence
without a named reason → kill/chill pop-up.
