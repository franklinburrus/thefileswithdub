# docs/ — the source of truth

**Declared by Frank 2026-09-22: GitHub docs/ is THE source of truth for all
law and doctrine text.** If two places disagree, this folder wins.

## The four layers (plus this one)

| Layer | Holds | Never holds |
|---|---|---|
| **GitHub docs/** (this folder) | Canonical law and doctrine text — the single authoritative copy of every standing rule | — |
| **Notion** | Explanations and guides — pointers to the canonical doc, plus the what and why in plain language | A second full copy of any law text |
| **Ledger** | Learning index — Project Decisions, Learning Log, Avoid List rows (what failed, what changed, why) | Structured project data, clip records, schedules |
| **Sheets** | Structured data — clip indexes, tracking tables, inventories | Doctrine text, decisions |
| **Drive** | Doctrine sources and binary assets — brand book, workflow PDFs, art masters, rendered files | Law text |

## Convention for law docs

Every law doc in this folder is written as: title + **"Law — approved by
Frank <date>"** + the rule sections, and carries the line:

**Canonical source — supersedes copies elsewhere.**

When a law changes, the change is made here first; Notion, AGENTS.md, and the
Ledger carry pointers and the learning story, not competing copies.
