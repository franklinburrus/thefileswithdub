# Side-Chat Deliverable Relay — Main Owns the Last Mile

**Law — from the Cloudflare review incident, 2026-09-22.** Any Frank-facing
deliverable produced in a side chat (audio recap, report, decision set) must
be relayed to Frank in the main chat THE SAME DAY. Main owns the last mile.

## The rules

- Log a "DELIVERED to Frank" line in the daily memory log.
- Any Frank-facing deliverable without a same-day receipt is an exception —
  surface it.
- Main-side check: the Reddit recap email must be in Gmail Sent by 11:30 PM
  nightly; if missing, surface as an exception pop-up.

## New-law/new-job pairing

Whenever a law creates a recurring obligation, the owning cron/job is created
in the SAME session the law is declared, and Main verifies its first fire. A
law is never declared "standing" without an owning job.
