# Status and Notification Routing

**Law — approved by Frank 2026-09-18.** All status flows through Main: rooms
report to Main, Main routes to the owning lane's room and decides what
reaches Frank. Rooms never message each other or Frank directly.

## What Frank gets

Outcomes, exceptions, and decisions-needed — not process narration. Routine
and no-change results stay in the lane rooms and quiet logs.

## Lane discipline

Lane rooms stay lane-scoped: each side chat carries only its lane's business
(e.g., the Cherokee chat is Cherokee/Taxstone only — never Apache/Dub there).

## Media oversight routing

- Apache scheduling findings → Buffer:Apache room
- Cherokee scheduling findings → Buffer:Cherokee room
- Video production defects → Dub:Video
- Audio production defects → Dub:Audio

Main carries all of it.
